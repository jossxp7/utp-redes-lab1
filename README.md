# 🧪 Laboratorio 1: Fundamentos de Redes y Seguridad (UTP)

## 🎯 Propósito del Laboratorio
Documentar el análisis básico de conectividad, modelo OSI/TCP-IP y captura/verificación de paquetes en entornos de red locales, como parte de la formación en la Licenciatura en Ciberseguridad de la Universidad Tecnológica de Panamá (UTP).

## 🗺️ Topología / Entorno de Trabajo
- **Sistema Operativo:** Linux (Ubuntu / Debian)
- **Herramientas utilizadas:** Terminal Bash, Wireshark, Cisco Packet Tracer
- **Red de prueba:** Subred local controlada (`192.168.1.0/24`)

## 📋 Procedimiento Realizado
1. Verificación de interfaces de red y direccionamiento IP mediante comandos de diagnóstico (`ip a`, `ping`, `traceroute`).
2. Inspección de tráfico ICMP y resolución ARP en la red local.
3. Documentación de resultados y buenas prácticas de seguridad perimetral básica.
